# 프로젝트 맞춤 AI 작업 지침서 (AGENTS.md)

이 파일은 AI 에이전트가 이 프로젝트(동대문 사입/주문 관리 시스템)를 작업할 때 **항상 최우선으로 읽고 지켜야 하는 규칙**을 정의합니다.

## 1. 도메인 지식 (동대문 시장 특화 로직)
- **은어 및 약어 자동 변환:** 사용자가 카카오톡이나 텍스트로 입력하는 시장 은어(예: APM, 럭스, 청평, 제평 등)를 시스템 정식 명칭으로 스마트하게 매핑해야 함.
- **'디' / 'd' 자동 분류 로직 (중요):**
  - 호수에 알파벳(a~f)이나 한글이 포함된 경우 (예: f10, 가-10) ➡️ **"디오트"**
  - 호수가 오직 숫자(혹은 숫자+하이픈)로만 이루어진 경우 (예: 1-10, 15) ➡️ **"디자이너(디자이너클럽)"**

## 2. UI/UX 및 실무 편의성 우선
- **화면 이탈 방지 (오버플로우 금지):** 모든 UI 요소(모달, 팝업, 드롭다운 등)는 어떠한 경우에도 사용자 기기의 화면(뷰포트) 사이즈 밖으로 벗어나지 않아야 하며, 무조건 화면 내부에 고정되거나 스크롤되도록 처리할 것.
- **모바일 최적화 및 제스처:** 모바일 환경에서 한 손으로 조작하기 편해야 함. (예: 달력 화면에서 좌우 스와이프로 월 이동 기능 필수 유지).
- **정보의 직관성 (공휴일 표시):** 달력에 공휴일을 표시할 때 단순히 날짜만 칠하는 것이 아니라, 다일(Multi-day) 연휴의 경우 `설날 (~12일)`과 같이 끝나는 날짜를 표기하여 일정을 한눈에 파악할 수 있게 함 (KST 타임존 기준 엄수).
- **동선 최소화:** 달력을 볼 때도 다른 팝업이나 화면 이동 없이 현재 화면에서 필요한 요약 정보를 바로 확인할 수 있는 UI 구조를 지향.

## 3. 작업 스타일 및 원칙
- **빠른 피드백 적용:** 사용자가 실무적인 비효율을 지적하면 즉각 수정하고, 반복되는 패턴은 이 문서에 업데이트하여 다음 작업에 반영할 것.
- **임의 UI 추가 금지:** 요청하지 않은 불필요한 기능(장식용 대시보드, 복잡한 네비게이션 탭 등)은 추가하지 않고, 핵심 기능(주문 등록, 정산, 내역 확인)의 속도와 정확성에 집중할 것.
